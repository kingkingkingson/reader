# 文档概要与按需阅读

2026-10-15 更新：文档聊天已切换为持续会话，具体存储、恢复和压缩策略见[持续文档会话](document-conversations.md)。下方概要生成机制继续使用；末尾性能数字保留为切换前的单次验证记录。

## 行为

Reader 复用 `document_corpora` 中的原文与位置，独立生成可保存的文档概要、术语、发现、限制和来源锚点。概要不依赖翻译，翻译的 JSONL 协议和缓存继续使用原实现。

“导入后生成文档概要”默认关闭。开启后仅安排新导入文档；历史文档通过文档概要入口按需生成。生成失败不会恢复翻译，也不会阻止原文问答。重新启动恢复中断任务，手动取消保留已完成分段，重试复用同一原文版本的分段提要。概要、任务和索引随文档删除清理。重新生成使用独立的 `document_overview_drafts` 检查点；旧概要与搜索索引在新概要成功提交前保持可用，失败／取消／重启后可以续做。新概要和索引在同一事务中替换，任务 ID 防止旧任务迟到写入。部分覆盖但已生成内容的概要也可真正重新生成。

短文档在输入预算内一次处理全文；长文档优先使用已有章节结构，PDF 只有物理页结构时按连续范围装入预算，不为每页单独发起模型请求。每批成功结束并完成结构、来源 ID 校验后保存提要；全文汇总超出预算时分组归并。解析缺失与编译完成度分开记录。

生成结果的来源校验保证引用锚点属于输入材料，不能替代对摘要内容忠实性的质量评测。文本索引无法表达的图表和公式结构继续沿用原有覆盖说明。

## Agent

`get_outline` 增加派生概要；`search_document` 保留原文检索；`read_passage` 支持互斥的单段、章节、PDF 页范围、全文选择器。范围结果按原文顺序返回，超出预算时提供 `nextCursor`，续读需要保持原选择器。EPUB 使用自身章节和定位。

概要充分时，总体介绍允许不重新读取原文；具体数字、方法核查、引文和翻译需原文。概要锚点不能直接作为 `[S数字]` 引用，只有读取工具返回的原文才进入该引用集合。会话分别标明概要和原文来源，不把概要覆盖度等同于本轮逐段阅读；版本有效的已读原文可以跨轮复用。

Codex 保留持久线程及原生 MCP 循环；API 保存消息窗口并在必要时压缩旧记录。两者在同一会话循环中直接完成阅读和回答，不再新开成文请求。正文继续通过现有 SSE 增量输出，成功终态与存储规则不变。达到阅读边界时，工具反馈要求使用已有资料完成回答；取消、来源过期和真实上游失败仍作为失败处理。

## 上下文与预算

- Codex：读取有效 `config/read` 中的 `model_context_window`，运行时使用 `thread/tokenUsage/updated.tokenUsage.modelContextWindow` 校正。`last` 的用量与累计计费用量分开处理，自动 compact 阈值不冒充窗口大小。
- API：保留 `/models` 的 `context_window`（DeepSeek）、`context_length` 和 `top_provider.context_length`（OpenRouter）等字段；选择实际请求模型的元数据。
- 手动值为上限；已知模型窗口较小时不能借此扩大模型能力。未知时采用 64K 保守值，并记录来源为 `fallback_estimate`。
- 文本 token 消耗为估算，不写入实际用量统计。四分之一窗口预留给指令、历史、工具封装和输出，阅读预算另外扣除已有问题和概要。
- 单次连续原文结果最多约 16K 估算 tokens。持续会话不按历史已读原文总量停止阅读：API 根据当前活动窗口调整返回量并压缩，Codex 使用自身上下文管理。原生 Codex 进程单独设置工具结果保存预算，避免默认值截断连续读取结果；不修改全局配置。
- 重复三次相同工具请求时收束；128 次工具调用、API 64 轮是单次交互的防失控边界，不作为文档完整度判断。文档交互上限为十分钟，不再拆分阅读与成文时间。

本阶段没有增加向量数据库或全库 Agent 搜索。API 长期对话压缩已在持续会话改动中实现；持久概览与原文工具不依赖聊天历史保留，可在后续会话重新读取。

## 验收

1. 导入已有解析的 PDF/EPUB，单独生成概要；观察封面和概要窗口进度、用量记录。
2. 重启后查看同一概要，确认没有重新生成；取消后重试长文档，确认复用已完成分段。
3. 问“这篇论文大致讲什么”，检查概要与原文阅读的区分；再问具体实验数字，检查原文引用。
4. 使用全文、页范围和章节读取，检查续读位置以及 PDF/EPUB 原生跳转。
5. 原文更新后旧概要显式过期，点击来源前再次验证版本；删除文档后无孤立索引。
6. 分别验证 Codex 配置/运行时窗口、API 模型窗口、手动上限和缺失元数据的回退。
